# Q: 這個專案的核心模組有哪些?

## Answer

fork260509-rev1 是 SoybeanAdmin 的 fork,橫跨三種技術棧。核心模組:(1) 授權子系統為整個專案重心 — NestJS AuthZ Service、Casbin Policy API、AuthZ Management/RBAC Service、Casbin Adapter(Rust)、API Key Auth,以 Casbin RBAC 為核心。(2) Rust 服務層 — App Bootstrap、Config & JWT、Redis Utility、IP2Region。(3) NestJS 後端 — CQRS User Handlers、Sys Menu/Misc Routers、Database Migrations。(4) Vue 前端 — Frontend Auth & Router、Vue Routes & Icons、CRUD API、Shared TS Types。(5) 文件規範 — Coding Standards、Naming Conventions。連結度前6名有4個是 AuthZ 相關。
